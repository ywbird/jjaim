# glyph-inspect

[`../../SPEC.md`](../../SPEC.md) v0.3 선언을 읽어 유니코드 대응을 조사하고, 실제 텍스처 레이어를
조합해 PNG 미리보기를 만드는 독립 CLI다. TTF를 만들거나 TTF 렌더러를 쓰지
않는다.

프로젝트 루트에서 `cd tools/inspector` 한 뒤 실행한다.

```sh
uv sync
uv run glyph-inspect list ../../examples/hangul.json
uv run glyph-inspect groups ../../examples/hangul.json --format json --parts
uv run glyph-inspect sheet ../../examples/hangul.json --output sheet.png
uv run glyph-inspect text ../../examples/hangul.json --text '가각나' --output text.png
uv run glyph-inspect text ../../examples/ascii.json --text 'ASCII' --output ascii.png
uv run pytest
```

## 구현 결정

명세가 남긴 선택은 아래처럼 정했다.

### 선언 해석

- JSON은 엄격하게 읽는다. 중복 키, 알 수 없는 필드, 잘못된 자료형, `NaN`류
  상수, 빈/역방향 범위, 반복 확장 후 범위 이탈, 순환, 유니코드 충돌은 모두
  오류다. `bool`은 정수가 아니다.
- 코드 포인트 입력은 `U+` 뒤 1자 이상 16진수를 허용하고, 출력은 최소 네 자리
  대문자 `U+XXXX`다. U+0000은 유효하고 서로게이트는 거부한다.
- `repeat` 확장 순서는 앞쪽 축이 바깥쪽인 사전식 조합 순서이고, 각 조합 안에서
  `from` 구간의 `j`가 안쪽이다. 임포트·`at`·확장 순서가 레이어 순서다.
- 이미지 명령은 선언의 모든 임포트 원본 참조와 유니코드 매핑 참조의 텍스처
  절단 영역을 미리 검사한다. `list`/`groups`는 텍스처 파일을 열지 않는다.
- `texture_sets`는 셋별 소스 이름과 이미지 경로만 등록한다. 그룹의 `texture`는
  셋·소스 이름을 참조하고 `start`·`direction`으로 추출 위치를 정한다. 없는 셋/소스는
  PNG 접근 없이 선언 오류(3), 없는 이미지 파일은 이미지 명령에서 리소스 오류(4)다.
- PNG만 지원한다. 다른 형식은 조용히 변환하지 않고 오류로 보고한다.
  `texture_sets`에 등록한 상대 이미지 경로는 선언 파일 디렉터리 기준이다.

### `sheet`

- `--columns`는 한 줄의 최대 슬롯 수다. 실제 슬롯 수가 더 적으면 빈 열을 만들지
  않는다. 페이지 모드의 마지막 페이지도 같은 규칙을 쓴다.
- 슬롯 크기는 매핑된 모든 결과 그룹의 최대 `size`와 `U+XXXX` 라벨 폭/높이로
  정한다. 글리프는 슬롯 왼쪽 위, `--border`가 있으면 테두리 여백 1픽셀 안쪽에
  놓는다. 라벨은 글리프 아래에 쓴다.
- `cell` 테두리는 그룹 `size` 사각형의 바로 바깥 1픽셀, `ink` 테두리는 알파가
  0보다 큰 화소의 최소 사각형 바로 바깥 1픽셀이다. 빈 글리프의 `ink` 테두리는
  없다.
- 배경은 글리프 합성 뒤에 적용한다. 라벨은 검정 글자 + 흰색 1픽셀 외곽선,
  테두리는 검정이다.
- 크기 한도(1억 화소, 한 변 32768픽셀)는 `--scale`을 적용한 최종 PNG 크기로
  검사한다. 한 장이 한도를 넘으면 페이지 분할을 요구하는 오류를 낸다.
- `--per-page N`의 매니페스트 형식:

  ```json
  {"total": 5, "pages": [
    {"file": "page-0001.png", "count": 2, "first": "U+0041", "last": "U+0042"}
  ]}
  ```

  페이지는 임시 파일에 모두 만든 뒤 이름을 바꾸고, 매니페스트를 마지막에 쓴다.
  재실행 시 현재 매니페스트에 없는 `page-*.png`는 지워 이전 묶음의 잔여물이
  남지 않게 한다.

### `text`

- `\r\n`과 단독 `\r`을 `\n`으로 바꾼 뒤에만 처리한다. 정규화·자모 조합·폴백
  탐색·커닝은 하지 않는다.
- 줄 높이는 유니코드 매핑이 있는 결과 그룹의 최대 세로 크기다. 매핑된 문자는
  그룹 가로폭만큼 전진한다. 미매핑 문자는 U+0000 매핑이 있으면 그 글리프와
  폭을, 없으면 매핑 그룹 최대 `(가로, 세로)`의 검정 1픽셀 윤곽 박스를 쓴다.
- 빈 문자열은 인수 오류(2), 유니코드 매핑이 전혀 없는 선언은 선언 오류(3),
  UTF-8 디코딩 실패는 인수 오류(2)다. 줄만 있는 텍스트는 허용하며, 모든 줄의
  폭이 0이면 PNG 폭을 1로 만든다.

### 출력과 오류

- `list`/`groups`의 파일 출력, PNG 저장은 같은 디렉터리의 임시 파일을 거쳐
  `os.replace`로 덮어쓴다. 실패한 임시 파일은 지운다.
- 종료 코드: 인수 2, 선언 구문·의미 3, 텍스처/출력/입력 경로 4, 성공 0.
  진단은 표준 오류에만 쓰고 예상 가능한 오류에는 트레이스백을 내지 않는다.
- `--parts`는 `--format json`에서만 허용한다. `--text-file -`은 표준 입력의
  UTF-8 바이트를 읽으며 U+0000도 문자 하나로 처리한다.
