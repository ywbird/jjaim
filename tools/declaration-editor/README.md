# Declarative Font Editor

`../../SPEC.md`의 그룹 선언을 브라우저에서 조사하고 편집하는 정적 페이지입니다. 서버나 빌드 단계가 없으며, 명세와 화면 요구 사항은 [`SPEC.md`](SPEC.md)에 있습니다.

## 실행

프로젝트 루트에서 정적 파일 서버를 띄우고 페이지를 엽니다.

```sh
python3 -m http.server 8000
# http://localhost:8000/tools/declaration-editor/
```

페이지가 열리면 `examples/hangul.json`을 자동으로 읽고 `examples/`의 PNG를 불러옵니다. 파일 서버 없이 열거나 다른 정의를 편집하려면 **JSON 열기**와 **텍스처 열기**를 사용합니다. 텍스처는 PNG 파일 이름으로 정의의 경로와 연결됩니다.

## 기능

- 그룹 목록과 검색: 그룹 이름, `U+AC00`, 문자, `그룹[인덱스]`
- 그룹 설명, 직계 자식/부모의 설명과 배치 수 표시
- 그룹 설명, 텍스처 시작 좌표/방향, 임포트 그룹·오프셋·`at`·반복 축 편집
- 선택한 글리프와 변경된 글리프, 직접 부모 글리프의 이전/이후 미리보기
- 세션 단위 실행 취소/다시 실행 (`Ctrl+Z`, `Ctrl+Shift+Z`)
- 유효성 검사를 통과한 정의를 `<이름>-edited.json`으로 내보내기

## 제한

- 정의 파일 하나를 메모리에서 편집합니다. 여러 파일로 나뉜 정의 집합은 아직 지원하지 않습니다.
- 크기, 글리프 수, 유니코드 매핑은 표시만 하고 직접 편집하지 않습니다.
- 실행 취소 기록은 페이지를 새로 고치면 사라집니다.
- 직접 부모 글리프가 200개를 넘으면 미리보기 목록에는 처음 200개만 표시합니다. 영향받는 총 개수는 그대로 표시됩니다.
- 텍스처가 없으면 빈 글리프로 그리며, 원본 정의 파일은 덮어쓰지 않습니다.

## 테스트

```sh
cd tools/declaration-editor
node --test
```

`src/model.test.mjs`는 예제 정의의 파싱, 임포트 확장, 유니코드 매핑, 검색, 유효성 검사, 직렬화를 검사합니다.
